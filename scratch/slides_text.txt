Enemy.java — A* Pathfinding & AI State Machine A* Pathfinding ArrayList open/closed lists. Lowest fCost selected per frame. Manhattan |dx|+|dy| heuristic for 4-directional grid. constructPath() walks parent chain. Finite State Machine enum State { CHASE, WANDER }. CHASE triggers within 10 tiles if among 4 closest. WANDER picks random free tile from Map. Performance & Separation Path recalculated every 15 frames. Slow-motion: skip every 3rd frame (gp.slowTimer). Euclidean distance < 15px triggers repulsion. for(Node n : openList) {   if(n.fCost < current.fCost) current = n; } public enum State { CHASE, WANDER }

GamePanel.java — Game Loop, Timers & State GamePanel is the central game loop controller. It owns every entity collection, manages game state transitions, drives all timers, and coordinates rendering — making it the spine of the entire architecture. slowTimer long — counts down frames of slow-motion. Enemy.update() skips every 3rd frame when > 0. ghostFreezeTimer int — Breathe ability freeze. Enemy.update() returns immediately while > 0. staggerTimer int — Rubble tile effect. Reduces Player moveSpeed to 40% for 2s (120 frames). GameMode enum CASUAL: enemies chase, exits open. ESCAPE: boss levels every 5 levels, exit locked until crystals collected. if(slowTimer>0) slowTimer--;  if(ghostFreezeTimer>0) ghostFreezeTimer--; exitLocked = (currentMode==GameMode.ESCAPE); // locked until all crystals

System Architecture — Component Overview Component Responsibility Main / GamePanel Entry point & game loop. Bootstraps JFrame, manages update/draw cycle, timers (slow/freeze/stagger), entity collections. GameMenu JavaFX front-end: menus, mode selection, scoreboard, FadeTransition animations. Player / KeyHandler Input polling via KeyListener; axis-independent collision; sprite rendering with fallback. Enemy / Node A* pathfinding with CHASE/WANDER FSM. ESCAPE mode forces WANDER. Node is the POJO data model. ArcherBoss / Arrow Shotgun + Frenzy + Machine-Gun burst attack phases. Arrow: vector movement, wall-tile deactivation. ExplosionTracker / Crystal 4-phase lerp-to-detonate mechanic. Crystal: boolean lifecycle, 18px expanded AABB bounds. Map / Tile Procedural int[][] world. 3 layouts: normal/arena/chase. Tile is a 6-entry Flyweight. ScoreEntry / ScoreManager CSV serialisation, BufferedWriter append, defensive parsing, lambda Comparator sort.

=== Slide 24:  ===
Conclusion Dungeon Escape demonstrates that a feature-complete game can be built from first principles in Java — without a game engine — using clean OOP architecture, hand-rolled algorithms, and deliberate design patterns. The 16-class codebase covers A* pathfinding (Enemy & ArcherBoss), procedural generation, vector mathematics, 3 distinct boss attack phases, cross-framework threading, file I/O, and four design patterns (Flyweight, Composite, Strategy, State Machine). Identified improvements — database integration, networked leaderboards, JUnit testing, and a central AssetManager — represent clear next steps toward a commercial-grade release.
